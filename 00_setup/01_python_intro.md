---

# 1. 프로그래밍이란?

프로그래밍(Programming)은 특정 목적을 달성하기 위한 프로그램을 설계하고 구현하는 과정입니다.

```text
문제 인식
   ↓
프로그램 설계
   ↓
프로그램 구현
   ↓
테스트와 디버깅
   ↓
유지보수
```

프로그래밍 학습은 단순한 문법 암기가 아니라 복잡한 문제를 작은 문제로 나누고 논리적으로 해결하는 방법을 익히는 과정입니다.

---

# 2. 코딩이란?

코딩(Coding)은 사람이 생각한 문제 해결 방법을 컴퓨터가 실행할 수 있는 프로그래밍 언어로 작성하는 작업입니다.

```python
a = 10
b = 20
result = a + b
print(result)
```

실행 결과:

```text
30
```

---

# 3. 프로그래밍 언어

대표적인 프로그래밍 언어에는 Python, Java, JavaScript, C, C++, Kotlin, Swift 등이 있습니다.

이 과정에서는 Python을 사용합니다.

---

# 4. Python이란?

Python은 1991년 Guido van Rossum이 개발한 프로그래밍 언어입니다.

Python은 작성된 코드를 해석하여 실행하는 인터프리터 방식의 언어이며, 문법이 비교적 간결해 입문자도 접근하기 쉽습니다.

---

# 5. Python의 특징

1. 문법이 비교적 이해하기 쉽다.
2. 빠르게 배울 수 있다.
3. 무료로 사용할 수 있다.
4. 코드가 간결하다.
5. 다양한 분야에서 사용할 수 있다.
6. 개발 속도가 빠르다.

---

# 6. 첫 번째 Python 코드

```python
print("Hello, Python!")
```

실행 결과:

```text
Hello, Python!
```

현재 단계에서는 다음 흐름만 이해하면 충분합니다.

```text
Python 코드 작성
       ↓
Python이 코드 해석
       ↓
컴퓨터가 명령 실행
       ↓
결과 출력
```

---

# 🧪 간단한 실습

```python

print("Hello")
print("Python")
```

예상 결과:

```text
Python Programming Start!
30
Hello
Python
```
