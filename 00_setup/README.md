# 00. Python 개발환경 구축

Python 프로그래밍을 시작하기 전에 필요한 기본 개념과 개발환경을 준비합니다.

이 과정에서는 Python 자체뿐 아니라 VS Code, Jupyter Notebook,
Python 패키지와 프로젝트 폴더 구조까지 단계적으로 학습합니다.

---

## 🎯 학습 목표

이 과정을 완료하면 다음을 할 수 있습니다.

- 프로그래밍과 코딩의 의미를 설명할 수 있다.
- Python의 특징을 이해할 수 있다.
- Python을 설치하고 정상 설치 여부를 확인할 수 있다.
- VS Code를 설치하고 Python 개발환경을 설정할 수 있다.
- Python 파일을 만들고 실행할 수 있다.
- Jupyter Notebook을 생성하고 실행할 수 있다.
- 데이터 분석용 Python 패키지를 설치할 수 있다.
- Python 프로젝트의 기본 폴더 구조를 이해할 수 있다.
