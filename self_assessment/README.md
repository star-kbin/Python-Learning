### 평가 방법

1. [문제 페이지](./TEST.md)에서 문항 30개를 읽고 ①~④ 중 답을 **종이 또는 메모장에 기록**합니다.
2. AI Agent·인터넷 검색·교재·다른 사람·코드 실행의 도움 없이 **혼자** 풉니다.
3. 각 영역 마지막에 있는 **접기/펼치기 정답·해설**을 열어 답을 확인합니다.
4. [점수 계산표](./SCORE_AND_LEARNING.md)에서 100점 만점 가중점수를 계산하고 레벨을 확인합니다.
5. 정답률이 낮은 영역의 추천 자료부터 공부합니다.

**권장 시간:** 25~35분 · **형식:** 4지선다형 30문항 · **응시 비용:** 무료 · **설치:** 불필요

> ⚠️ GitHub Markdown은 정답 선택 내역을 자동 저장하거나 점수를 자동 계산하지 않습니다. 현재 방식은 **자가 기록·자가 채점**입니다. 공개 정답이 존재하므로 감독된 객관적 시험이나 채용 평가용으로 사용하지 마세요. 실습 코딩 능력을 측정하는 공식 자격증도 아닙니다.

### 독립 응시 원칙

**실제 자신의 실력을 확인하기 위해 응시 중 ChatGPT, Copilot, Claude 등 AI Agent, 검색, 강의자료, 주변 사람의 도움을 사용하지 마세요.** 자신의 지식으로 먼저 답하고, 채점을 마친 다음 부족한 부분을 공부할 때 AI를 활용하는 것은 좋습니다.
