# Python & Data Skills Assessment

파이썬 및 데이터 분석 기초 역량을 **스스로 점검**하는 무료 자가진단입니다.

## 응시 안내
- 총 **30문항**, 권장 **20~30분**, 100점 만점
- **AI Agent(ChatGPT·Claude·Copilot 등), 검색, 주변 사람의 도움, 외부 코드 실행 및 자동완성을 이용하지 마세요.**
- 시험 감독·AI 사용 탐지 기능은 없습니다. 응시자의 자율적인 독립 응시를 전제로 합니다.
- **비공인 자가진단**이며 실습형 코딩 능력, 채용 적합성, 공인 자격을 입증하는 시험이 아닙니다.
- GitHub 공개 저장소 특성상 정답 열람이 가능하며, 시험 보안을 보장할 수 없습니다.

## 실행 방법
```bash
pip install -r self_assessment/requirements.txt
streamlit run self_assessment/app.py
```
터미널의 안내에 따라 브라우저에서 테스트를 진행합니다.

## 측정 영역과 가중치
|영역|배점|문항 수|
|---|---:|---:|
|Python 문법·자료구조|25|7|
|코드 해석·디버깅|20|6|
|데이터 처리·전처리|25|6|
|통계·시각화|15|4|
|분석 문제 해결|15|7|

가중점수는 영역별 정답률 × 영역 배점의 합계로 계산합니다.

## 결과 레벨(초기 가설)
- Level 1 입문: 0–39점
- Level 2 기초: 40–59점
- Level 3 실무 기초: 60–74점
- Level 4 실무 활용: 75–89점
- Level 5 심화: 90–100점

영역별 정답률이 낮은 학습 내용을 우선 추천합니다. 레벨 구간과 문항은 추후 실제 응시자 자료로 문항 변별도·난이도를 분석해 개선해야 합니다.

## 운영 및 개인정보
응시자의 답변은 Streamlit 세션 상태에 보관되며 별도 DB에 기록하지 않습니다. 사용자는 결과를 JSON으로 내려받을 수 있습니다. 새로운 응시 시 문제 순서가 섞입니다. 문제와 정답은 `questions.json`에서 수정할 수 있습니다.

## 후속 확장
실제 프로그래밍 능력의 객관성을 높이기 위해 Jupyter Notebook + 자동화 테스트(pytest) 기반 실습 평가를 별도 추가하는 것을 권장합니다.
