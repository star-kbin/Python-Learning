## 1. 점수 계산

각 영역의 맞힌 개수를 세어 다음 표에 적어 보세요. **가중점수 = 영역 배점 × (정답 수 ÷ 해당 영역 문항 수)** 입니다. 다섯 영역의 가중점수를 더해 **100점 만점**으로 계산합니다. 최종 합계만 소수 첫째 자리로 반올림합니다.

|평가 영역|문항 수|배점|내 정답 수|가중점수 계산|
|---|---:|---:|---|---|
|A. Python 문법·자료구조|7|25|___ / 7|25 × 정답 수 / 7|
|B. 코드 이해·오류|6|20|___ / 6|20 × 정답 수 / 6|
|C. Pandas·데이터 처리|6|25|___ / 6|25 × 정답 수 / 6|
|D. 통계·시각화|4|15|___ / 4|15 × 정답 수 / 4|
|E. 데이터 분석 사고|7|15|___ / 7|15 × 정답 수 / 7|
|**합계**|**30**|**100**||**___ / 100점**|

예: A영역 5문항 정답이면 25 × 5/7 = 약 **17.86점**입니다. 5개 영역 점수를 모두 더해 총점을 산출합니다.

## 4. 권장 학습 루틴

1. 오답 해설을 보고 모르는 개념을 **3개 이내**로 정리합니다.
2. 취약 영역의 참고 학습자료를 읽고, 예제 코드를 **스스로** 작성해 봅니다.
3. 1~2주 뒤 같은 문항을 다시 풀어보되, **기억 효과 때문에 점수 향상을 실제 실력 향상으로 단정하지 않습니다.**
4. 새 문제로 확인하거나 작은 데이터 분석 과제를 완성하여 역량을 재점검합니다.

응답이나 점수를 저장·수집하지 않으며, 본인 메모를 기준으로 스스로 진단합니다.
