## 1. 점수 계산

**맞힌 문제의 배점만 더하면 최종 점수입니다. 총 30문항, 100점 만점이며 소수점 계산이나 반올림이 필요 없습니다.**

- 정답: 해당 문항의 배점 전부를 받습니다.
- 오답·미응답: 0점입니다. 부분점수와 감점은 없습니다.
- 빠른 계산: **최종 점수 = 100 − (오답·미응답 문항의 배점 합계)**.
- 기존 영역별 총배점(25·20·25·15·15점)은 유지하고, 계산 편의를 위해 문항별 정수 배점으로 배분했습니다. 같은 영역에서도 문항마다 배점이 다르므로 정답 개수만으로 점수를 계산하지 마세요.

## 4. 권장 학습 루틴

1. 오답 해설을 보고 모르는 개념을 **3개 이내**로 정리합니다.
2. 취약 영역의 참고 학습자료를 읽고, 예제 코드를 **스스로** 작성해 봅니다.
3. 1~2주 뒤 같은 문항을 다시 풀어보되, **기억 효과 때문에 점수 향상을 실제 실력 향상으로 단정하지 않습니다.**
4. 새 문제로 확인하거나 작은 데이터 분석 과제를 완성하여 역량을 재점검합니다.

응답이나 점수를 저장·수집하지 않으며, 본인 메모를 기준으로 스스로 진단합니다.
